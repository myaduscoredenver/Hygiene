# 7794 Hygiene — Property Intelligence

Static client-preview site using the uploaded Hygiene MLS master CSV and photos of 7794.

## Deploy
1. Create a GitHub repository.
2. Upload all files and the `assets/` directory.
3. Import the repository in Vercel. Choose **Other** framework, no build command, output directory `.`.
4. The site also opens locally by double-clicking `index.html`.

## Data / limitations
- `data.js` includes the supplied 639 MLS records and 14 curated sales.
- The $1.225M starting reference is a preliminary human estimate; the Value Laboratory is a transparent heuristic weighted average, not a trained estimator or appraisal.
- The $679,000 acquisition and financial costs are illustrative pending verification.
- MLS comp photographs are intentionally not republished without licensing review.
- Confirm IRES display/redistribution rules before sharing the deployment.
